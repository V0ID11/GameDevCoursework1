============================================================
DESCRIPTION
============================================================

Retro Essential SFX is a curated collection of classic retro-style
sound effects designed for video games and interactive projects.

This pack focuses on clean, punchy, and versatile 8-bit / retro-inspired
audio suitable for a wide range of game genres, including platformers,
arcade games, roguelikes, puzzle games, prototypes, and UI-heavy projects.

All sounds are designed to be lightweight, game-ready, and easy to
integrate into Unity projects with minimal setup.

Tip: Although the sounds are titled and categorized, feel free to repurpose
and rename them however you like! The UI sounds are great for other
actions as well!

============================================================
CONTENTS
============================================================

This package includes 93 sound effects, covering the following categories:

• UI / Menu Sounds
• Player Actions
• Combat & Impacts
• Game Events & Stingers
• Footsteps
• Loops
• Miscellaneous Effects

Each category includes multiple variations where applicable to help reduce
audible repetition during gameplay.

============================================================
AUDIO SPECIFICATIONS
============================================================

• File Format: WAV
• Sample Rate: 48,000 Hz
• Bit Depth: 24-bit
• Channels: Mono (except loops where applicable)
• Normalization: Balanced for in-game use
• Designed for real-time playback in Unity

============================================================
RECOMMENDED UNITY IMPORT SETTINGS
============================================================

Suggested default settings for most one-shot sound effects:

• Load Type: Decompress On Load
• Compression Format: PCM
• Force To Mono: On
• Normalize: Off
• Sample Rate Setting: Preserve Sample Rate
• Preload Audio Data: On

For longer loops, Vorbis compression may be used if desired.
